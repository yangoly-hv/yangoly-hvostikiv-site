# Інструкція для власника: банка Monobank для сайту

На сайті є **два різні** місця з банкою Monobank:

| Де на сайті | Що покласти в Sanity | Навіщо |
|---|---|---|
| Кнопки «Разова допомога» і форма в hero | Публічне посилання `https://send.monobank.ua/jar/…` у **Налаштування сайту** → `monobankJarUrl` | Відкрити сторінку банки для разового донату |
| Блок головного збору (ціль, зібрано) | **`longJarId`** з віджета банки в документі збору (`collection`) | Показати баланс/ціль і кнопку «Підтримати збір» |

Нижче — інструкція саме для **блоку збору** (`longJarId`). Посилання для разової допомоги вставляється як є, без віджета.

---

## Що саме потрібно

| # | Що | Секрет? | Куди |
|---|-----|---------|------|
| 1 | **`longJarId`** з віджета банки («Віджет для стрімів») | Ні | Sanity: поле `monobankLongJarId` у головному документі збору (`collection`), або спочатку звичайний чат розробникам |

Усе інше (назва банки, ціль, поточний баланс, коротке посилання для донату) сайт підтягне **автоматично** з публічного API Monobank.

Опційно (корисно, але не обов’язково) напишіть одним рядком:
- для якого місяця / збору ця банка (наприклад: «серпень 2026, головний блок на головній»).

---

## Безпека

### Можна надсилати у звичайний чат
- `longJarId` (рядок літер і цифр з віджета)
- публічне посилання на банку, якщо хочете додатково перевірити сторінку: `https://send.monobank.ua/jar/...`

### Не треба надсилати
- пароль від Monobank
- коди з SMS / push
- API-токен з https://api.monobank.ua/ (для цього блоку **не потрібен**)
- токени з кабінету еквайрингу

---

## Як взяти `longJarId`

Робіть у **тому самому** акаунті Monobank (фонд / БО), де лежить потрібна банка.

1. Відкрийте застосунок або веб-сторінку банки Monobank.
2. Відкрийте потрібну банку.
3. Знайдіть **«Віджет для стрімів»** (зазвичай внизу / у налаштуваннях банки).
4. Відкрийте налаштування віджета.
5. Скопіюйте **`longJarId`**:
   - з адресного рядка браузера (параметр `longJarId=...`), **або**
   - з посилання «Скопіювати віджет» — параметр `jar=...` у тому посиланні (це і є longJarId).

Приклад вигляду (не використовуйте цей приклад як свій):

`2zQL6sqnKgTYi7eVz71YYWKTXTfMK8g`

Це **не** коротке посилання `send.monobank.ua/jar/AU9j...`. Короткий код сайт отримає сам з API.

6. **Перевірка (для себе):** відкрийте публічну сторінку банки в браузері без входу в банк — має бути назва і кнопка донату. На сайт у Sanity все одно йде саме **`longJarId`**, не це посилання.

Надішліть `longJarId` розробникам звичайним повідомленням або вставте в Sanity самі, якщо є доступ.

```text
[ ] банка саме та, яку показуємо на сайті
[ ] баланс банки можна показувати публічно на сайті
```

## Що буде далі (для розуміння)

Після отримання `longJarId` розробники:
1. Запишуть його в Sanity у поле **`monobankLongJarId`** головного документа збору (`collection`).
2. Сайт через публічний API Monobank підтягне **назву**, **ціль**, **поточний баланс** і коротке посилання для кнопки донату.
3. На головній кнопка «Підтримати збір» відкриє сторінку банки Mono; рядок «Зібрано» показує баланс і ціль з банки.
4. Якщо банку не вдалося підтягнути, кнопка лишається на WayForPay, а сума береться з Sanity.
5. Сума оновлюється періодично (раз на хвилину). Окремий webhook і API-токен **не потрібні**.

### Зміна банки щомісяця (серпень → вересень)

1. Створіть нову банку в Monobank (або візьміть наступну).
2. Візьміть новий **`longJarId`** з віджета нової банки.
3. У Sanity відкрийте головний збір (`collection` з `main`) і оновіть поле **`monobankLongJarId`**.

---

## Чого робити не треба

- Не давайте логін/пароль Monobank і не просіть розробників «зайти самим».
- Не плутайте `longJarId` з коротким кодом у `send.monobank.ua/jar/...`.
- Не надсилайте повні виписки рахунку — достатньо `longJarId`.
- Не шукайте токен на https://api.monobank.ua/ для цього блоку — він більше не використовується.

## Часті питання

**Чи зможе сайт зняти гроші з банки?**  
Ні. Сайт лише **читає** публічні дані банки (назва, ціль, баланс) і показує посилання для донату.

**Чому не оновлювати суму вручну?**  
Можна, але цифри швидко роз’їдуться з реальною банкою. `longJarId` якраз щоб блок був актуальним.

**У нас кілька банок — що надсилати?**  
Лише **`longJarId` тієї однієї**, яку показуємо зараз, і чітко підпишіть призначення (наприклад «головна на головній»).

**Банка на акаунті фонду (БО), а не особиста — це ок?**  
Так. Саме для цього й потрібен `longJarId` з віджета, а не особистий API-токен.
